# Лабораторная работа №2: Регулярные выражения и Unit-тесты

**Тема:** Поиск промокодов и скидок в тексте  
**Выполнила:** Борисоглебская Полина

## Описание
Программа находит промокоды в тексте (состоящие из 3-15 заглавных латинских букв или цифр). Ищет коды, которые идут после слов «промокод», «промо» или «скидка». Поддерживает ввод текста, чтение из файла и скачивание страницы по URL.

## Навигация по репозиторию
- **[Исходный код (main.py)](./main.py)** — реализация регулярного выражения и интерфейса.
- **[Unit-тесты](./test_main.py)** — 10 тестов для проверки надежности регулярки.
- **[Отчет о выполнении](./ppLab2.docx)** — оформленный отчет.
- **[Зависимости](./requirements.txt)** — список сторонних библиотек.

## Как запустить
1. Установите зависимость (для работы с URL):
   ```bash
   pip install -r requirements.txt
2. Запустите программу:
   ```bash
   python main.py
3. Для запуска тестов:
   ```bash
   python -m unittest test_main.py -v

## Используемые технологии
- Python 3.10+
- Регулярные выражения (`re`)
- HTTP-запросы (`requests`)
- Unit-тестирование (`unittest`)

## Результаты тестирования
Все 10 unit-тестов успешно пройдены. Покрыты следующие случаи:
- Поиск с разными разделителями (пробел, двоеточие, тире).
- Поиск нескольких промокодов и удаление дубликатов.
- Игнорирование строчных букв, слишком коротких (<3) и длинных (>15) кодов.
- Регистронезависимый поиск ключевого слова.
